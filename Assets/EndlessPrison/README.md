# 無盡牢獄：第一區（Unity 可玩切片）

整個資料夾 `EndlessPrison` 放進你 Unity 專案的 `Assets` 裡就能玩，不需要另外安裝套件或模型。

## 怎麼開始

1. 把 `EndlessPrison` 資料夾放到 `E:\無盡D&D\Assets\` 底下，切回 Unity 等它編譯完。
2. 上方選單點 **無盡牢獄 → 開啟第一區並遊玩**。
   （會自動建立 `Assets/EndlessPrison/Scenes/FirstArea.unity` 場景並按下 Play）
3. 選難度，開始。

如果選單沒出現：開一個新場景，建立一個空物件（GameObject → Create Empty），把 `GameManager` 腳本拖到它身上，按 Play。

## 操作

| 按鍵 | 作用 |
|---|---|
| 左鍵點地板 | 移動 |
| 左鍵點有光點的物件 | 調查（會跳出選項和成功率） |
| 左鍵點敵人 | 探索時：繞過去偷襲／戰鬥中：用選好的行動攻擊 |
| 1～7 | 戰鬥行動：攻擊、猛力劈砍、推擊、投擲、閃避、起身、乾糧 |
| 空白鍵 | 結束回合 |
| Q／E | 旋轉鏡頭 |
| 滾輪 | 縮放 |
| Tab | 線索本 |

## 這一版有什麼

- **3D 人物**：主角和敵人是關節人偶，有走路、戰鬥架勢、攻擊、猛力劈砍、推擊、踹、投擲、受擊、閃避、倒地、墜落等動作（都是程式算出來的，不用動畫檔）。
- **起始牢房**：稻草堆（木籤）、斷裂腳鐐（鐵條）、87 道刻痕、陶碗（陶片）、鐵柵欄（擠過去／踹開／撬鎖）。
- **深淵環道**：倒下的火盆（碎石）、枯骨（遺書、乾糧）、水窪（腳步聲變大）、木桶（擋視線）、斷掉的石欄（可以把人推下坑）。
- **戰鬥**：每回合 4 AP＋6 公尺移動；命中率顯示（綠／黃／橘／紅）、優勢劣勢、背後攻擊、倒地、推擊、地形殺。
- **第一階段線索**：衣領編號、門鎖在外面、三天口糧、腳鐐的尺寸……

## 想調整難度

全部數字在 `Scripts/Game/Difficulty.cs`。例如敵人血量 `EnemyHP`、每回合最多攻擊次數 `EnemyMaxAttacksPerTurn`。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `Scripts/Level/FirstArea.cs` | 地圖、物件擺放、所有劇情文字和檢定 DC |
| `Scripts/Game/GameManager.cs` | 點擊、探索、檢定、回合制戰鬥 |
| `Scripts/Game/EnemyBrain.cs` | 「不懷好意的男人」的 AI |
| `Scripts/Characters/HumanoidRig.cs` | 3D 人偶和所有動作 |
| `Scripts/UI/Hud.cs` | 畫面介面、骰子動畫 |

## 之後可以做的

- 換成真正的 3D 模型和動作（例如 Mixamo 免費角色）：只要替換 `HumanoidRig`，其他程式不用改。
- 油畫濾鏡（Kuwahara）、畫布質感、降飽和 LUT。
- 職業選擇（戰士／遊蕩者／法師）、第二區。
